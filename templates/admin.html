An admin can see and delete every account on this install, including yours, and can promote anyone else. Confirm with your own password.

To add someone, send them this server's /register page. They create their own account, then you promote them here. Only the first account ever created is an admin automatically. The last remaining admin cannot be removed or deleted — an install with flight data and nobody able to administer it has no way back short of editing SQLite by hand.
